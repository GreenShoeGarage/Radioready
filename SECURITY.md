# Security Policy

## Supported version

Security fixes are applied to the current release of RADIOREADY.

## Reporting a vulnerability

Please do not publish an exploitable vulnerability in a public issue. Report it privately through GitHub's **Security → Report a vulnerability** feature when enabled for the repository.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Avoid including real customer compliance records, proprietary schematics, credentials, or personal information.

## Security model

RADIOREADY is a static, local-first application. It has no backend, account system, telemetry, or required network connection. Project data is stored in the browser's local storage and in JSON files explicitly exported by the user.

Users remain responsible for protecting exported projects and referenced evidence. Browser storage is not a controlled records system or secure document vault.
